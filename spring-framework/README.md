# Module 05 — Spring Framework

> **Module guide:** Understand Spring's container, dependency injection, bean lifecycle, configuration, and proxy-based features.

## Learning outcomes

- Explain how the container creates and wires application objects.
- Choose constructor injection and understand bean scope/lifecycle.
- Recognize when Spring proxies affect method behavior.
