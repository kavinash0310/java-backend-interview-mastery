# Module 04 — Data Structures and Algorithms

> **Module guide:** Practice the data structures, problem-solving patterns, and complexity analysis used in Java coding interviews.

## Learning outcomes

- Choose a suitable data structure from problem requirements.
- Explain algorithm complexity and trade-offs.
- Write clear Java solutions and handle edge cases.

## Topic coverage

### Foundations and linear structures

- Time and space complexity
- Arrays and strings
- Linked lists
- Stacks and queues
- Hashing and hash-based lookup

### Trees, graphs, and search

- Trees and binary search trees
- Heaps and priority queues
- Graphs and traversal
- Searching and sorting

### Problem-solving techniques

- Recursion and backtracking
- Two pointers and sliding windows
- Dynamic programming fundamentals
- Common Java coding interview questions

## Where questions belong

Create a Markdown page for each distinct interview question. Place it in the matching subtopic folder, or group closely related questions in a module-level interview guide. Suggested subtopic folders:

- `data-structures-algorithms/foundations-and-linear-structures/` — foundations and linear structures question pages
- `data-structures-algorithms/trees-graphs-and-search/` — trees, graphs, and search question pages
- `data-structures-algorithms/problem-solving-techniques/` — problem-solving techniques question pages

Use descriptive lowercase kebab-case filenames, for example `data-structures-algorithms/some-topic/question-name.md`. Avoid duplicate questions; improve the existing entry when the intent is the same. Add new entries to this module's question index and link related topics instead of copying answers.
