# Module 24 — Online Assessment Practice

> **Module guide:** Prepare for timed coding questions, multiple-choice fundamentals, and basic aptitude checks.

## Learning outcomes

- Read question constraints and identify edge cases before coding.
- Explain time and space complexity in plain language.
- Review MCQ answers by understanding why the other choices do not fit.

## Topic coverage

- Java and object-oriented programming MCQs
- Exception handling
- DBMS concepts and normalization
- Basic quantitative aptitude
- Common string, linked-list, array, and map problems
