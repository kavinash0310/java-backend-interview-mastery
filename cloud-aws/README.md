# Module 18 — Cloud and AWS

> **Module guide:** Understand the cloud building blocks used to deploy, secure, scale, and operate backend applications on AWS.

## Learning outcomes

- Map application components to suitable cloud services.
- Apply least privilege and keep secrets out of source code.
- Balance availability, performance, and cost.

## Subtopic links

- [Cloud and identity foundations](#cloud-and-identity-foundations)
- [Application infrastructure](#application-infrastructure)
- [Production concerns](#production-concerns)

## Topic coverage

### Cloud and identity foundations

- Cloud service models and shared responsibility
- AWS regions and availability zones
- IAM identities, policies, and least privilege

### Application infrastructure

- Compute options
- Object and block storage
- Virtual networking and security groups
- Managed relational and NoSQL databases
- Managed messaging services

### Production concerns

- Secrets management
- High availability and scalability
- Deployment architecture
- Security and cost considerations
