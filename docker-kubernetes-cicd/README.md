# Module 17 — Docker, Kubernetes and CI/CD

> **Module guide:** Package backend services, run them in containers, and understand deployment automation and recovery.

## Learning outcomes

- Distinguish image build-time settings from runtime configuration.
- Explain how Kubernetes controllers maintain desired state.
- Design a deployment path with health checks and rollback options.
