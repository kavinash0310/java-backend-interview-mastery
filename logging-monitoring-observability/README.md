# Module 19 — Logging, Monitoring and Observability

> **Module guide:** Make backend behavior diagnosable through useful logs, metrics, traces, health signals, and incident practices.

## Learning outcomes

- Choose logs, metrics, or traces for a diagnostic question.
- Use correlation IDs to follow requests across services.
- Turn incidents into evidence-based fixes and actionable alerts.

- [Signals and context](#signals-and-context)
- [Monitoring and alerting](#monitoring-and-alerting)

## Topic coverage

### Signals and context

- Structured logging
- Metrics and service-level indicators
- Distributed tracing
- Correlation and trace IDs

### Monitoring and alerting

- Dashboards and alert design
- Health checks and readiness
- Latency, traffic, errors, and saturation
- Reducing noisy alerts

### Production investigation

- Incident investigation and communication
- CPU, memory, and thread analysis
- Performance troubleshooting
- Production debugging and post-incident learning
