# Module 09 — SQL and Relational Databases

> **Module guide:** Query and model relational data while understanding indexes, transactions, isolation, and database performance.

## Learning outcomes

- Write accurate queries and model related data.
- Explain when indexes help and what they cost.
- Reason about transaction isolation and concurrent updates.

- [SQL and schema design](#sql-and-schema-design)

## Topic coverage

### SQL and schema design

- SQL fundamentals and data types
- Joins, subqueries, and common table expressions
- Normalization and relational modeling
- Constraints and database design

### Indexes and query performance

- Index structures and trade-offs
- Query plans and optimization
- Connection pooling
- Database performance diagnosis

### Transactions and concurrency control

- ACID properties
- Transaction boundaries
- Isolation levels and anomalies
- Locks, blocking, and deadlocks
