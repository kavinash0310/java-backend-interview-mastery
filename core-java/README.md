# Module 01 — Core Java

> **Module guide:** Build fluency in the Java language and standard library, from syntax and object-oriented design through collections and modern Java features.

## Learning outcomes

- Explain core language behavior with small examples.
- Choose standard library types based on their contracts and trade-offs.
- Write readable Java that uses modern language features appropriately.

## Topic coverage

### Fundamentals and syntax

- Java syntax and program structure
- Primitive and reference types
- Variables, operators, control flow, and methods
- Classes, objects, and constructors

### Object-oriented programming

- Encapsulation, inheritance, polymorphism, and abstraction
- Interfaces and abstract classes
- Composition versus inheritance
- Overloading and overriding

### Strings and core object contracts

- String immutability
- StringBuilder and string handling
- equals() and hashCode() contracts
- Object methods and value objects

### Collections framework

- List, Set, Map, and Queue
- ArrayList, LinkedList, HashSet, and TreeSet
- HashMap internal working and collision handling
- Iteration, ordering, and collection trade-offs

### Exceptions and generics

- Checked and unchecked exceptions
- Exception propagation and custom exceptions
- Generic types, methods, and bounds
- Wildcards and type erasure

### Java 8 and modern Java

- Lambda expressions and functional interfaces
- Streams and collectors
- Optional and null handling
- Date and Time API
- Modern language features such as records, sealed types, and pattern matching (version dependent)
