# Module 16 — Maven, Gradle, Git and GitHub

> **Module guide:** Manage Java dependencies and repeatable builds, and collaborate safely with Git and GitHub workflows.

## Learning outcomes

- Explain how dependency resolution and build lifecycles work.
- Choose merge or rebase based on collaboration context.
- Submit small, traceable changes with clear review history.
