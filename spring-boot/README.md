# Module 06 — Spring Boot

> **Module guide:** Build and operate Spring applications using Boot auto-configuration, configuration management, REST support, and operational features.

## Learning outcomes

- Explain how auto-configuration responds to classpath and configuration.
- Build a clean REST endpoint with validation and consistent errors.
- Expose operational information safely for deployment and monitoring.

- Spring Boot Actuator
- Logging and configuration management
- Health and readiness endpoints
