# Module 07 — REST APIs and HTTP

> **Module guide:** Design predictable, secure, and documented HTTP APIs with sound resource modeling and client-friendly behavior.

## Learning outcomes

- Select appropriate methods and status codes for an API operation.
- Design stable pagination, errors, and versioning strategies.
- Explain idempotency and its role in safe retries.

- [HTTP and REST foundations](#http-and-rest-foundations)

## Topic coverage

### HTTP and REST foundations

- HTTP request and response structure
- Methods, status codes, headers, and content types
- REST resource modeling and constraints
- Safe and idempotent operations

### API contracts and usability

- Pagination, filtering, and sorting
- API versioning and compatibility
- Validation and error responses
- OpenAPI documentation

### Cross-cutting web concerns

- CORS
- Authentication and authorization at the API boundary
- Caching and conditional requests
- Rate limiting and request size limits
